## 03 — Featured Engineering Project

# 🛰️ EdgeVision

### Intelligent Vision. Optimized Intelligence. Secure Communication.

*Bringing computer vision closer to the edge.*

</div>

**EdgeVision** is an ongoing research and engineering project focused on developing an edge-based intelligent image processing and secure cyber-physical communication system for unmanned aerial vehicles (UAVs).

The project explores the balance between AI model accuracy, computational efficiency, hardware limitations and communication security.

### Engineering objectives

| Component | Technical Direction |
|---|---|
| Visual Intelligence | UAV object detection |
| Edge Optimization | FP32, FP16 and INT8 |
| Model Deployment | ONNX and edge inference |
| Performance Analysis | Latency and resource benchmarking |
| Communication Security | MAVLink and secure communication |
| Experiment Tracking | MLflow and PostgreSQL |

### Technology ecosystem

`Python` `PyTorch` `YOLO` `OpenCV` `ONNX` `Docker` `MLflow` `PostgreSQL` `MAVLink`

## 04 — AI × Cybersecurity

<div align="center">

*Intelligence needs security. Security needs intelligence.*

</div>

I'm particularly interested in the security challenges emerging as intelligent systems become increasingly integrated into real-world applications.

My exploration focuses on:

- **LLM Security:** Prompt injection and vulnerabilities in language-model applications.
- **Adversarial ML:** Understanding how manipulated inputs affect model behavior.
- **AI-driven Security:** Exploring intelligent threat detection and anomaly analysis.
- **Cyber-Physical Systems:** Investigating secure communication and system reliability.
- **Trustworthy AI:** Robustness, reliability and responsible deployment.

My long-term goal is to understand how intelligent systems can be designed with security as an engineering requirement rather than an afterthought.
